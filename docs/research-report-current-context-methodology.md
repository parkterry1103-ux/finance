# 작성 시점 맥락 반영 방법론

## Snapshot 정책

리포트는 뉴스 cutoff와 가격·시장·재무·가치평가·업종 benchmark 기준일을 분리해 고정한다. runtime 외부 요청은 없으며 새 뉴스 반영은 새 버전 배포로만 한다.

## 선별 절차

기존 read-only 뉴스와 기업 IR·SEC·공식 산업·거시 자료를 모은 뒤 중복·홍보·단순 주가·근거 불명 기사를 제거한다. 남은 사건 중 수요, 가격, 점유율, 마진, Capex, 운전자본, 현금흐름, 자본구조, 규제, 장기 ROIC, WACC 또는 성장률을 바꿀 수 있는 사건만 기업당 최대 3건 선택한다.

확정 자료와 보도 단계를 구분한다. 기술 발표는 상용화·고객 채택·매출 시점·대체 범위가 확인되기 전까지 장기 가정을 즉시 바꾸지 않는다. 각 사건은 영향받는 assumption과 metric, 전달 경로, 지속성, 판단 영향과 다음 지표를 가진다.

## 시장과 기업 요인

금리·유동성·위험회피·경기·지정학은 시장 전체 요인, 실적·가이던스·제품·고객·규제 직접 영향·자본구조는 기업 고유 요인으로 나눈다. 같은 기간 상대수익률이 있어도 인과를 확정하지 않는다.

## 판단 체계

상단에는 사업 판단, 해자, 재무건전성, 산업 사이클 역할 네 판단을 표시한다. 점수·별점은 사용하지 않고 각 판단마다 근거와 변경 조건을 둔다. 뉴스는 `기존 판단 유지`, `일부 가정 수정`, `추가 확인 필요`, `핵심 가정 재검토` 중 하나로 설명한다.

## 뉴스와 가치평가 연결

사건은 기존 가정, 검토 범위, 매출·마진·재투자·ROIC·Terminal Value로 이어지는 경로와 현재 모델 변경 여부를 명시한다. 보도 단계 사건에 임의 확률을 부여하지 않는다. 공식 수치가 다음 재무제표에 반영되기 전에는 순현금·자본구조 변화를 임의 결합하지 않는다.
