# 기업 판단 모델

Phase 5I는 기업 상세 첫 화면에서 정보량보다 판단 순서를 우선한다.

## 공개 구조

1. 기업 방향: 향후 6~12개월의 사업·실적·현금흐름
2. 시장 기대: 다음 1~2개 분기의 기대 수준·가이던스·투자 부담
3. 본업 성장
4. 이익의 질
5. 현금의 질
6. 투자·재무 부담

두 상단 판단을 합산하는 종합 의견·점수·등급은 만들지 않는다. 네 판단 카드는 처음에 모두 닫히며 한 번에 하나만 열린다.

상단 두 판단은 하나의 외곽 카드 안에서 얇은 구분선으로 나뉜 세로 2행으로 표시한다. 각 행은 방향, 기간, 한 문장 이유만 항상 보여주며 별도의 배경·테두리·radius를 갖지 않는다. `최근 사건과 주가 반응`은 네 판단 아래의 기본 접힘 보조 정보이고, Phase 5I 기업에는 별도 `다음 확인` 섹션을 만들지 않는다.

## 카드 계약

각 카드는 `state`, `reason`, `trend`, 3단계 `causeFlow`, 2~3개의 `metrics`, 하나의 `reversalCondition`, `sourceIds`를 가진다. `주의`는 데이터 부족 상태가 아니라 실제 긍정·부정 근거가 충돌할 때만 사용한다. 근거가 없거나 stale인 카드는 `확인 부족`으로 만들지 않고 렌더링에서 제외한다.

## 최신성

`latestQuarterlyResultsAt`보다 먼저 검토한 본업 성장·이익의 질·현금의 질 카드는 현재 판단으로 사용할 수 없다. `latestMaterialEventAt`보다 먼저 검토한 투자·재무 부담과 시장 기대도 사용할 수 없다.

각 판단은 `asOf`, `reviewedAt`, `analysisVersion`을, 근거는 `publishedAt`, `period`, `sourceType`, `sourceTitle`, `sourceUrl`, `scope`, `metricDefinition`을 보존한다.

새 공시나 중요 이벤트를 registry의 latest update에 먼저 등록하면 기존 분석은 freshness gate에서 숨겨진다. 운영자는 새 분석을 승인한 뒤 기준일과 검토일을 갱신한다.

Phase 5I 등록 여부와 현재 판단 유효성은 분리한다. 등록 기업의 `buildCompanyJudgment()`가 `null`이면 기존 Company Dissection을 현재 판단으로 되살리지 않고 `최신 실적을 반영한 분석을 준비하고 있습니다.`와 이전 분석 기준일만 표시한다. 미등록 기업만 기존 Company Dissection 화면을 유지한다.

## 근거 공개

기본 화면에는 출처를 나열하지 않는다. 카드가 열린 뒤 `근거 자료 보기`를 다시 펼쳤을 때만 제목, 유형, 기준 시점, 기간, 범위, 지표 정의, 링크와 한계를 보여준다. 공식 공시·기업 IR·거래소·공공통계는 `공식 원문 보기`, 산업자료·외부 분석자료는 `원문 보기`로 구분한다.

## 내부 이상 징후

`anomalyReview`는 사용자 UI에 노출하지 않는다. 일회성 손익, 충당금, 감액·환입, 이익과 현금의 차이, 재고·매출채권, 부채·조달, 비정상 마진을 운영자가 검토한 기록만 보존한다.
