# 공시 원자료 선택 정책

## 우선순위

1. SEC EDGAR filing과 CompanyFacts, OpenDART 정기공시의 실제 접수 문서를 사용한다.
2. 최신 완료 정기공시를 가격 기준일 이전에 제출된 문서 중에서 선택한다.
3. 수정 공시는 같은 기간·계정의 원공시보다 우선한다.
4. 지원 한국 기업은 연결재무제표 CFS를 사용한다. 연결 공시가 있는 기업에 OFS를 자동 대체하지 않는다.
5. 보도자료와 IR 자료는 공시값을 해석하거나 교차 확인하는 보조 자료다.

## lineage 필수 항목

회사, metric ID, 값, 통화, 단위, 기간 시작·종료, 회계연도·분기, reported/derived origin, form·접수번호, 제출일, 연결 기준, concept/account ID, 원문 URL, 검증일을 추적한다. 파생값은 공식 ID와 모든 input ID를 추가한다.

## freshness와 no look-ahead

`current`는 가격 기준일 현재 사용 가능한 최신 완료 공시가 반영된 상태다. `stale`은 더 최신 공시가 있는데 반영하지 못한 상태, `filing_pending`은 실적 발표 뒤 정기공시 접수 전 상태다. `filedAt > priceAsOf`인 공시는 해당 시점 계산에 사용할 수 없다.

## 보류 기준

통화, 단위, 연결/별도, 기간 길이, 계정 정의, 정정 기준 중 하나라도 일치하지 않으면 계산을 중단한다. 결측은 실제 0과 구분하며 추정·보간하지 않는다.

## Netflix 2026 Q2 source identity

- 최신 10-Q: accession `0001065280-26-000212`, period end `2026-06-30`, filed `2026-07-17`
- 같은 실적 발표 8-K: accession `0001065280-26-000211`, filed `2026-07-16`
- 최근 연간 10-K: accession `0001065280-26-000034`, period end `2025-12-31`, filed `2026-01-23`

가격 기준일과 10-Q 제출일이 같은 2026-07-17인 경우 filing 제출 사실과 정규장 종가의 시간 순서를 조용히 추정하지 않는다. 이번 재무 화면은 최신 완료 공시 identity와 가격 기준을 각각 표시하고, 시장 멀티플 audit에서는 필요한 분모가 같은 세션 전에 이용 가능했는지 별도로 확인한다.
