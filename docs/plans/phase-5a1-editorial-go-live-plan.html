03 · Policy

owner verified와 명칭 정책

계획

Owner Verified

작성자와 검증자가 owner이고 검증 시각을 가진 편집 기록입니다. 사건이나 미래 결과를 보증하지 않고, 사실·숫자를 작성자가 확인했다는 의미만 갖습니다.

authoredBy: owner · verifiedBy: owner · status: ownerVerified

오늘의 월스트리트

내부 ThreeReadsEdition과 기존 `/ko/insights/3reads/:slug`는 유지하되 사용자 화면만 변경합니다.

05 · Information Architecture

홈페이지와 상세 표시 구조

계획
  1. Published 요약 index만 홈에서 로드합니다.
  2. 홈에는 주가 해부 핵심값과 월스트리트 세 사례를 짧게 표시합니다.
  3. 상세 원고는 기존 lazy route에서 불러옵니다.
  4. 사실·전망·해석·Not Yet Final을 제목으로 구분합니다.
  5. 긴 선정·검증 과정은 키보드 접근 가능한 details에 둡니다.
