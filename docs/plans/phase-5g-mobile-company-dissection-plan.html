목적과 사용자 흐름

모바일 사용자가 10초 안에 성장성·수익성·해자·재무건전성·밸류에이션을 구분해 읽고, 선택한 축의 근거만 확인하도록 만듭니다. 단기 사건과 시장 기대는 구조적 기업 해부에 합산하지 않습니다.

  1. 홈에서 기업 검색
  2. 네 개 핵심 카드
  3. 오각형 축 선택
  4. 근거 패널 확인
  5. 필요한 상세 화면 이동

현재 홈 감사

  • 주요 섹션 4개: 검색 hero, 주가해부, 월가인사이트, 중복 기업 찾기 CTA
  • 검색은 Company Registry 기반 경량 metadata를 사용
  • Published summary만 eager이며 본문은 route 단위 dynamic import
  • 거시·재무·가치평가 미리보기는 현재 핵심 홈에 없음
  • 중복 기업 찾기 CTA는 제거 후보

현재 기업 상세 감사

  • 첫 화면에 다섯 질문, 최대 3개 지표, Event Impact, 관련 해부, 최대 3개 CTA
  • 이어지는 assessment·전체 지표·차트·변화·거시 변수로 설명과 숫자가 반복
  • 긴 상세 자료는 details 안에 있으나 모바일 진입부가 여전히 길음
  • 밸류에이션 미지원 CTA는 숨김 처리됨
  • 새 구조에서 다섯 질문은 축 패널·다음 확인으로 압축

현재 범위의 기준점 차이

요청문에는 지원 기업 8개와 Netflix 미게시 상태가 적혀 있으나 실제 main에는 Netflix를 포함한 9개와 7월 18일 콘텐츠가 이미 Published입니다.

  • 기존 Published·point-in-time·공시 lineage는 삭제하지 않음
  • 이번 단계에서 Netflix 콘텐츠를 신규 게시하거나 내용 수정하지 않음
  • 현재 지원 기업 9개 모두 검색·기업 해부 validation에 포함
  • Phase 5F provider·custom event flag는 변경하지 않음

업종·사업부·peer 정책

  • GICS/대표 지수, ICB/거래소, 금융정보 분류 3개를 기록
  • 다수 분류 일치 결과를 대표 업종으로 사용
  • 공식 공시의 사업부를 별도 보존
  • 연결 성장·재무건전성은 자체 과거 우선
  • 동일 정의 비교가 확인된 축만 peer 기준 사용
  • 복합기업은 축·지표별 비교 기준을 분리

오각형 비교 규칙

  • 내부 위치 단계: 낮은 편~높은 편, 합산 점수 없음
  • 성장·수익성: 동일 정의 peer가 없으면 자체 추세
  • 재무건전성: 순현금·현금흐름·투자 부담의 자체 과거
  • 밸류에이션: 검증 모형 또는 동일 정의 멀티플만 사용
  • 해자: 공식 근거·약화 조건·다음 확인으로 판단
  • 확인 부족은 중간점으로 대체하지 않고 별도 상태로 표시
