03 · Audit

현재 재무 화면 감사 결과

코드 변경 전 완료

현재 경로

Company Brief의 숫자와 비교 보기는 같은 상세 페이지의 #company-dashboard-metrics-title로 이동합니다. 독립 재무 route는 없고 기존 상세에는 최신 metric 카드·차트와 별도의 legacy 분석 route가 있습니다.

현재 데이터

정적 dashboard는 기업별 최신 지표 1~5개입니다. 기존 /api/financials는 SEC CompanyFacts 또는 OpenDART의 최신 기간과 일부 YoY·QoQ를 반환하지만 연속 피벗 시계열을 공개 모델로 제공하지 않습니다.

기존 계산·원문·재작성 처리
SEC normalization은 최신 적용 가능한 filing/context를 선택하고 amended filing을 restated로 기록합니다. 기존 API는 FCF, 부채비율, 유동비율, 이자보상배율을 계산합니다. TTM은 현재 공개 화면에 없으며 안전한 연속 4분기가 없으면 새로 표시하지 않습니다.

07 · Calculation

계산 규칙과 결측치

32개 단위 검증

YoY·QoQ

양수 분모와 동일 부호일 때만 변화율을 계산합니다. 적자→흑자는 흑자전환, 흑자→적자는 적자전환, 음수끼리는 적자확대·축소로 표시합니다.

마진·CAGR

마진과 비율 차이는 %p입니다. CAGR은 시작·종료가 양수이고 실제 연속 간격이 최소 3개일 때만 표시합니다.

누락

null·undefined·미수집·해당 없음은 0으로 바꾸지 않습니다. 자료 없음·비교 불가·기간 부족을 구분합니다.
