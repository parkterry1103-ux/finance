01 · Purpose

이번 단계가 해결하는 문제

계획

제품 질문

현재 가격은 어떤 성장·마진·경쟁력 지속성을 요구하며, 내부 모형과의 차이는 어떤 기대에서 생기는가?

금지되는 결론

목표가격·상승여력·매수·매도·점수는 만들지 않습니다. 가격과 모형의 차이를 행동 신호로 바꾸지 않습니다.

02 · Phase 5C

이전 단계 완료 상태

완료

8개 기업의 연간 5개 기간 재무 피벗, 자체 추세·비교기업·업종 비교와 결측치 보호 규칙이 Production에 배포됐습니다. Phase 5D는 이 실제 추세를 가치평가 가정과 연결하되 정의와 기간이 같은 경우에만 직접 비교합니다.

03 · Audit

현재 가치평가 기능 감사

완료

계산 엔진

결정론적 FCFF, WACC, 영구성장, Enterprise-to-Equity bridge, 3개 시나리오, 5×5 민감도와 Reverse DCF가 존재합니다.

공개 화면

NVIDIA·Meta 리서치의 긴 본문 중간에 가치평가가 포함되어 있습니다. 전용 route와 기업 상세 CTA는 없습니다.

데이터 로딩

리포트 route와 두 기업 데이터는 이미 dynamic import입니다. 신규 API 없이 이 경계를 재사용합니다.

감사한 입력과 안전 규칙
7년 전망, 매출 성장 경로, 정상 영업이익률, 세율, D&A, Capex, 운전자본, WACC, 영구성장률, 장기 ROIC, 순현금·순부채, 리스, 희석주식 수와 출처를 확인했습니다. WACC > g, 양의 주식 수, 동일 통화, 시나리오 순서와 유한값 validation도 기존 엔진에 있습니다. 별도 valuation API나 Serverless Function은 없습니다.

06 · Model

가치 범위·내재 기대·프리미엄 후보

구현 예정

모형 가치 범위

보수·기준·낙관 시나리오를 한 축과 텍스트로 보여주며 범위 밖 가격도 잘리지 않게 합니다.

내재 기대

현재 가격을 기준으로 매출 CAGR 하나만 역산합니다. 마진·WACC·재투자·영구성장률은 기준 가정에 고정합니다.

프리미엄 후보

성장 지속, 해자, 신사업 옵션, 수급 등 근거 상태와 다음 확인 지표를 표시하되 금액으로 나누거나 합산하지 않습니다.

주요 가정·민감도·연결 계획
첫해 성장률, 장기 마진, WACC, 영구성장률, 7년 전망을 기본 노출합니다. WACC·영구성장률은 제한된 로컬 입력과 초기화를 제공하고 5×5 민감도는 시맨틱 표와 내부 스크롤로 구현합니다. 기업 상세·재무 피벗·NVIDIA/Meta 리포트를 상호 연결합니다.

08 · Data & Version

모형 버전과 결측치 규칙

구현 예정

버전 기록

모형 버전, 모형·재무·가격·마지막 검증일을 각각 표시합니다. 가격만 최신 저장값으로 갱신된 경우 가격 업데이트로 구분합니다.

안전한 결측

0, 빈 그래프, 임의 업종값을 만들지 않습니다. 역산 해가 범위 안에 없으면 계산 불가와 탐색 범위를 함께 표시합니다.

09 · Accessibility & Performance

접근성·모바일·로딩 계획

검증 예정

접근성

h1 하나, heading 순서, 텍스트 범위값, marker accessible label, th·scope, label 연결과 44px target을 검사합니다.

모바일

320px부터 페이지 overflow 0을 유지하고 민감도 표만 내부 스크롤합니다. marker와 통화·입력값 겹침을 확인합니다.

성능

valuation UI는 route chunk, 기업 데이터는 NVIDIA·Meta별 dynamic chunk로 유지합니다. 초기 홈과 기업 상세에서 엔진을 선로딩하지 않습니다.
