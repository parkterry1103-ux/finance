03 · Audit

현재 가치평가 기능 감사

완료

계산 엔진

결정론적 FCFF, WACC, 영구성장, Enterprise-to-Equity bridge, 3개 시나리오, 5×5 민감도와 Reverse DCF가 존재합니다.

공개 화면

NVIDIA·Meta 리서치의 긴 본문 중간에 가치평가가 포함되어 있습니다. 전용 route와 기업 상세 CTA는 없습니다.

데이터 로딩

리포트 route와 두 기업 데이터는 이미 dynamic import입니다. 신규 API 없이 이 경계를 재사용합니다.

감사한 입력과 안전 규칙
7년 전망, 매출 성장 경로, 정상 영업이익률, 세율, D&A, Capex, 운전자본, WACC, 영구성장률, 장기 ROIC, 순현금·순부채, 리스, 희석주식 수와 출처를 확인했습니다. WACC > g, 양의 주식 수, 동일 통화, 시나리오 순서와 유한값 validation도 기존 엔진에 있습니다. 별도 valuation API나 Serverless Function은 없습니다.
