# Monte Carlo 가치평가 방법론

## 목적

확률적 가치평가는 하나의 결과를 확정하는 도구가 아니다. 4A에서 이미 검증한 FCFF DCF에 근거가 있는 입력 범위를 반복 적용해 `선택한 가정 안에서 모형 결과가 얼마나 달라지는가`를 보여준다. 결과 분포는 미래 주가 분포가 아니다.

## 재사용하는 4A 계산

모든 유효 표본은 `src/domain/valuation/scenarios.ts`의 `runScenario`를 호출한다.

```text
FCFF = EBIT × (1 − 세율) + 감가상각 − Capex − 운전자본 증가
기업가치 = 명시적 FCFF 현재가치 + Terminal Value 현재가치
Terminal 재투자율 = 영구성장률 ÷ Terminal ROIC
주당 모형 결과 = 주주가치 ÷ 희석주식 수
```

별도 DCF 수식이나 화면 표시용 반올림 숫자 재계산은 없다. WACC 표본은 기존 자본구조, 무위험금리, ERP와 부채비용을 유지하고 levered beta를 역산한 뒤 기존 WACC 공식으로 다시 계산한다.

## 입력과 분포

회사마다 의미 있게 달라지는 6개 입력만 사용한다.

- 전망 매출 CAGR
- 정상 영업이익률
- Capex/매출
- 운전자본 재투자/매출
- WACC
- 영구성장률

기본 분포는 삼각분포이며 4A 보수·기준·낙관 값을 각각 범위와 mode의 근거로 삼는다. `기준값 ±20%` 같은 임의 규칙은 사용하지 않는다. CAGR 표본은 숫자 하나로 모든 연도를 덮어쓰지 않고, 표본이 위치한 두 4A 시나리오의 연도별 성장 경로를 보간한다. 마진, Capex와 운전자본도 같은 방식으로 연도별 경로를 보간한다.

장기 ROIC와 감가상각률은 세 시나리오가 동일하므로 고정한다. 이 변수를 임의 표준편차로 흔들지 않는다.

## 재현 가능한 난수

PRNG는 작은 Mulberry32 계열 구현이며 unsigned 32-bit seed를 받는다. `Math.random`과 신규 난수 library는 사용하지 않는다.

- NVIDIA seed: `2026071701`
- Meta seed: `2026071702`
- 최종 시도 횟수: 회사별 `50,000`
- 생성 시각 metadata: `2026-07-17T03:00:00.000Z`

같은 입력, seed와 엔진 버전에서는 같은 순서의 표본과 집계 결과가 나온다.

## 표본 검증과 제외

각 표본은 4A validation과 다음 검사를 통과해야 한다.

- `WACC > 영구성장률`
- 희석주식 수가 양수
- 통화 일치
- 모든 입력과 결과가 finite
- 매출 성장률, EBIT margin, Capex/매출과 운전자본 재투자가 경제적 허용 범위 안
- `0 ≤ Terminal 재투자율 ≤ 1`
- 주당 결과가 양수

오류를 clamp로 숨기지 않는다. 제외 사유를 집계하며 제외율이 5%를 넘으면 실행을 실패시킨다.

## 통계

유효 표본에서 평균, 표준편차, 최소·최대, P5·P10·P25·P50·P75·P90·P95를 선형 보간 분위수로 계산한다. 현재 시장가격 기준일과 가치평가 기준일이 같을 때만 경험적 누적분포에서 현재 가격의 백분위를 계산한다.

입력 영향도는 Spearman rank correlation으로 계산한다. 동률에는 평균 순위를 사용한다. 공개 화면은 절댓값 기준 상위 5개를 보여주지만, 이것은 모형 내부 영향도이며 인과관계가 아니다.

## 수렴과 교차검증

같은 50,000회 실행의 prefix에서 10,000회, 25,000회, 50,000회를 비교한다.

- P10, P50, P90
- 평균과 표준편차
- 상위 3개 입력 순서

25,000회와 50,000회의 P10·P50·P90 상대 차이가 각각 1% 이하여야 한다. 4A 보수·기준·낙관 결과와 P10·P50·P90은 강제로 일치시키지 않는다. 결정론적 양 끝 조건은 여러 유리하거나 불리한 입력이 동시에 적용되지만 독립 추출 표본에서는 항상 같은 방향으로 결합되지 않기 때문이다.

## Terminal Value 진단

모든 표본에서 `Terminal Value 현재가치 ÷ 기업가치`를 저장하고 다음을 공개한다.

- 비중 P50
- 비중 P90
- 80% 초과 표본 비율

장기 구간 의존도가 높다는 뜻이지 미래 주가 손실 가능성을 뜻하지 않는다.

## 한계

- 분포 밖의 극단 사건은 포함하지 않는다.
- 입력 사이의 실제 상관행렬을 추정할 충분한 관측 표본이 없어 독립 추출한다.
- 독립 추출의 한계를 줄이기 위해 각 핵심 입력은 단일 연도 숫자가 아니라 4A의 연도별 경로를 보간한다.
- 현재 가격 백분위는 가정 분포와 시장가격의 상대 위치일 뿐 향후 방향에 대한 진술이 아니다.
