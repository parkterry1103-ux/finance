# Reverse DCF 방법론

## 역산 대상과 고정 조건

Phase 5D는 한 번에 `revenueCagr` 하나만 역산한다. 기존 기준 시나리오의 영업이익률 경로, 정상 세율, 감가상각, Capex, 운전자본, WACC, 영구성장률, Terminal ROIC, 현금·비영업자산·부채·리스·기타 청구권과 희석주식 수는 고정한다. 예측 기간은 기업 모형의 7년이다.

목표 함수는 역산한 동일 CAGR을 전망 연도에 적용한 주당 모형 계산값과 관측 시장가격의 차이다. 결정론적 이분법을 사용하고 상대오차 허용값은 `1e-7`, 공개 탐색 범위는 -20%~100%다. 결과를 다시 모형에 넣어 수렴을 검증한다.

## 표시와 비교

화면은 역산 변수, 유효 범위, 예측 기간, 가격·계산일, WACC·영구성장률, 장기 마진, 재투자 조건, 순현금·순부채와 희석주식 수를 함께 표시한다. 결과는 시장의 확정 전망이 아니라 다른 조건을 고정한 모형상 요구 조건이다.

최근 실제 연간 매출 CAGR과 기준 시나리오의 등가 미래 CAGR은 정의와 기간을 명시한 채 나란히 보여준다. 서로 다른 기간을 같은 성과로 단정하지 않는다. 회사 가이던스, peer 또는 업종 값은 동일 정의의 검증 데이터가 있을 때만 추가한다.

## 안전 처리

- 시장가격과 모형 통화가 다르면 역산하지 않는다.
- 가격·모형 날짜가 없거나 가격·주식 수가 0 이하이면 validation 실패다.
- 해가 없거나 수렴하지 않거나 -20%~100% 밖이면 `현재 설정 범위에서는 유효한 내재 성장률을 계산할 수 없습니다.`를 표시한다.
- 범위를 무한히 넓히거나 극단값을 공개하지 않는다.
- `WACC <= 영구성장률`, NaN, Infinity, 비정상 terminal value는 계산 제한이다.
- 여러 변수를 동시에 풀어 식별 불가능한 결과를 만들지 않는다.
