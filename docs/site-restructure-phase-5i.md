# Phase 5I — 기업 상세 판단 구조와 최신성

## 구현 범위

- 기업 상세 상단에 단일 외곽 카드와 세로 2행으로 기업 방향·시장 기대 표시
- 네 판단 카드의 단일 오픈 아코디언
- 추세·3단계 원인·핵심 수치·판단 변경 조건
- 중첩된 근거 자료 disclosure
- 기본 접힘 `최근 사건과 주가 반응`, Phase 5I 기업의 별도 `다음 확인` 제거
- 최신 분기·중요 이벤트 기반 stale gate
- stale 판단은 준비 상태와 이전 분석 기준일로 대체하고 legacy 핵심 카드로 fallback하지 않음
- SK하이닉스, Alphabet, 하나금융지주의 공식 자료 기반 판단
- Alphabet과 하나금융지주의 검색·기업 상세 route

## 산업별 해석

- SK하이닉스: 고부가 메모리 믹스, 마진, 순현금, M15X·용인·EUV 선행 투자
- Alphabet: Services·Cloud 성장, 세그먼트 마진, 영업현금·CAPEX·FCF, Wiz 인수
- 하나금융지주: 일반영업이익의 원천, 대손비용·NPL, 예금·대출 조달, CET1·위험가중자산

하나금융의 현금의 질은 일반 기업 FCF가 아니라 예금과 대출의 성장 균형 및 조달 안정으로 정의한다.

## 보존·제외

홈, 인사이트, 검색, 기존 기업 route, Financial Pivot, Valuation, Research Report, Event Impact와 Toss 전역 테마를 유지한다. 신규 dependency, API, DB, Serverless Function은 추가하지 않는다. 경쟁력·해자 축이 충분히 완성되지 않은 초기 세 기업의 오각형은 표시하지 않는다.
