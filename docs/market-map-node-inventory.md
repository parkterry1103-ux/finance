## 1. AI 반도체

기존 노드는 모두 기업 노드다. NVIDIA 앵커와 아래 23개 기업이 함께 표시된다.

- 수요·플랫폼: Google / Alphabet, Microsoft, Amazon
- AI 칩·ASIC: NVIDIA, AMD, Broadcom, Marvell
- 메모리·HBM: SK하이닉스, 삼성전자, Micron
- 파운드리·제조: TSMC, Intel
- 장비·소재·후공정: ASML, 한미반도체, 리노공업, ISC, 원익IPS, 솔브레인
- 서버·네트워크: Super Micro, Dell, Arista Networks
- 전력·냉각: Vertiv, Eaton, Schneider Electric

혼재 노드는 없지만 `AI 수요 → AI 칩 → HBM → 파운드리 → 장비/전력`이라는 기존 단계가 공통 다섯 질문과 다르고, 공급 기업·사용처·확인 항목이 별도 taxonomy로 고정돼 있지 않았다.

## 2. 데이터센터 전력·냉각

### 실제 기업 노드 4개

- Vertiv (`datacenter-power-vertiv`)
- Eaton (`datacenter-power-eaton`)
- Schneider Electric (`datacenter-power-schneider`)
- LG전자 (`datacenter-power-lg-electronics`)

### `Company`로 잘못 등록된 비기업 노드 6개

- 수요: AI 서버 증가
- 수요 결과: 전력 사용 증가
- 제품·기능: UPS / 전력 관리
- 제품·기능: 냉각 / HVAC
- 사용 결과: 운영 안정성
- 확인 항목: 데이터센터 투자 검증

### 잘못 섞인 관계 11개

- AI 서버 증가 → 전력 사용 증가
- 전력 사용 증가 → UPS / 전력 관리
- 전력 사용 증가 → 냉각 / HVAC
- UPS / 전력 관리 → Vertiv
- UPS / 전력 관리 → Eaton
- UPS / 전력 관리 → Schneider Electric
- 냉각 / HVAC → Vertiv
- 냉각 / HVAC → LG전자
- UPS / 전력 관리 → 운영 안정성
- 냉각 / HVAC → 운영 안정성
- 운영 안정성 → 데이터센터 투자 검증

이 관계들은 산업 구조 설명에는 유효하지만 기업 전용 관계망의 edge로 사용할 수 없다.

## 3. 재건·인프라

### 기업 노드 6개

- 현대건설, 삼성물산, 대우건설
- HD현대인프라코어, Caterpillar, POSCO홀딩스

### 비기업 노드 13개

- 기대·수요: 종전 기대감, 재건 수요
- 사용처: 도로 / 항만, 주택, 플랜트
- 발주·실행: 인프라 발주, 수주, 공사 진행
- 필요 요소: 건설장비 수요, 철강·소재 수요
- 확인 결과: 매출, 영업이익, 현금흐름

### 혼재 관계 25개

- 기대·수요: 종전 기대감 → 재건 수요
- 수요·사용처: 재건 수요 → 도로 / 항만·주택·플랜트
- 사용처·발주: 도로 / 항만·주택·플랜트 → 인프라 발주
- 발주·기업: 인프라 발주 → 현대건설·삼성물산·대우건설
- 기업·계약: 현대건설·삼성물산·대우건설 → 수주
- 실행·필요 요소: 수주 → 공사 진행 → 건설장비 수요·철강·소재 수요
- 필요 요소·기업: 건설장비 수요 → HD현대인프라코어·Caterpillar, 철강·소재 수요 → POSCO홀딩스
- 기업·결과: 수주·HD현대인프라코어·Caterpillar·POSCO홀딩스 → 매출 → 영업이익 → 현금흐름

산업 단계 edge와 기업 관계 edge를 구분할 수 없고, 기업 간 edge는 따로 존재하지 않았다.

## 4. 반도체 클러스터 인프라

### 기업 노드 6개

- 동양파일, 현대건설, 삼성물산
- LS ELECTRIC, 효성중공업, KCC

### 비기업 노드 14개

- 기대·주체: 정책 발표, 지자체 추진, 기업 투자 계획
- 사업 기반: 부지, 예산, 인허가, 전력 공급 계획
- 발주·사용처: 산업단지 조성, 공장 발주
- 확인 항목: 공급계약, 수주잔고, 매출, 영업이익, 현금흐름

### 혼재 관계 28개

- 정책 발표 → 지자체 추진·기업 투자 계획
- 지자체 추진 → 부지·예산·인허가
- 기업 투자 계획 → 전력 공급 계획
- 부지·예산·인허가 → 산업단지 조성
- 전력 공급 계획·산업단지 조성 → 공장 발주
- 공장 발주 → 현대건설·삼성물산·동양파일·LS ELECTRIC·효성중공업·KCC
- 각 기업 → 공급계약 → 수주잔고·매출 → 영업이익 → 현금흐름

정책·부지·발주·기업·계약·실적이 동일한 노드 문법을 사용하고, 기업 간 관계는 따로 존재하지 않았다.

## 정규화 결정

산업 구조 노드는 모든 지도에서 다음 순서를 고정한다.

1. `demand` — 수요는 어디서 생기나요?
2. `requirement` — 무엇이 필요해지나요?
3. `supplier` — 어떤 기업이 공급하나요?
4. `use` — 어디에 사용되나요?
5. `verification` — 무엇을 확인해야 하나요?

기업 연결 노드는 `company`만 허용한다. 지역은 기업 본사·실질 국적을 기준으로 `us`, `kr`, `other`에 매핑하며 상장 시장은 국가 분류를 덮어쓰지 않는다. 기업 간 직접 계약이 확인되지 않은 관계는 `industry` 신뢰도로 표시하고 관계 설명에서 직접 계약이 아님을 명시한다.
