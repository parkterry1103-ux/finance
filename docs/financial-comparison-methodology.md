# 재무 비교 방법론

> Phase 5C.1 보정: 분기 비교는 배열상 직전 값이 아니라 전년 동기의 동일 fiscal period를 우선한다. 독립 분기·누적 차감·TTM·공시 lineage의 상세 규칙은 [독립 분기와 TTM 계산 정책](./quarterly-financial-derivation.md), 멀티플은 [시장 멀티플 계산 방법론](./market-multiple-methodology.md)을 따른다.

## 연간·분기 정의

연간은 SEC 10-K 또는 OpenDART 사업보고서의 회계연도 값이다. 분기는 SEC 10-Q 또는 OpenDART 정기보고서에서 직접 확인된 최근 값이다. 누적 YTD를 독립 분기로 바꾸려면 동일 시작일·통화·연결 범위와 직전 누적 기간이 모두 확인돼야 한다. Phase 5C 공개 API는 이 조건을 충족하지 않는 누적값을 임의 분기값으로 변환하지 않는다.

## YoY·QoQ

금액과 주당 지표의 YoY는 `(현재 - 전년 동기) / |전년 동기| × 100`이다. QoQ는 같은 회계 기준의 직전 독립 분기끼리만 같은 공식을 쓴다. 기간 길이, 누적/독립 구분, 통화가 다르면 계산하지 않는다.

이전 값이 0이면 `기준값 0 · 증가율 미계산`으로 표시한다. 이전과 현재의 부호가 다르면 백분율 대신 `적자 → 흑자` 또는 `흑자 → 적자`로 표시한다. 둘 다 음수일 때는 사용자가 원금액을 읽도록 하며 보편적인 긍정·부정 판정을 붙이지 않는다.

## 마진과 비율

마진·수익률의 기간 변화는 상대 증가율이 아니라 `현재 비율 - 이전 비율`의 퍼센트포인트(%p)다. 예를 들어 19.8%에서 24.3%는 `+4.5%p`다.

## CAGR

`(마지막 값 / 첫 값)^(1 / 기간 간격 수) - 1`을 사용한다. 시작값과 종료값이 모두 양수이고 연속된 연간 기간이 둘 이상일 때만 계산한다. 시작값 또는 종료값이 0·음수이거나 기간 간격이 없으면 표시하지 않는다.

## 과거 중앙값·peer median

과거 중앙값과 peer median은 finite number만 오름차순 정렬한 뒤 중앙값을 사용한다. 짝수 개면 가운데 두 값의 단순 평균이다. Phase 5C peer 화면은 통화 변환 없이 비교 가능한 영업이익률, 순이익률, 잉여현금흐름률만 비교한다. 절대 금액은 통화가 다르면 비교하지 않는다.

peer group은 사업 흐름을 기준으로 수기 검증한다.

- 반도체: SK하이닉스, NVIDIA, Micron. 절대 금액이 아니라 비율만 비교한다.
- AI 서버: Dell, Supermicro.
- LG전자, Eaton, Meta: 현재 직접 peer를 확정하지 않고 안전한 빈 상태를 표시한다.

## 업종 집계

기존 NYU Stern 2026-01 미국 산업 스냅샷을 사용한다. 표본 수, 기준일과 원문을 함께 표시한다. 현재 기업과 동일 정의로 계산 가능한 자본 대비 차입금만 직접 붙인다. 산업 ROIC는 산식이 다른 기업 계산값과 직접 비교하지 않는다.

## 통화·회계연도 불일치

통화 환산 API를 추가하지 않았다. KRW와 USD 절대값은 비교하지 않고 비율만 사용한다. 회계연도 종료월이나 기간 길이가 다르면 `같은 회계연도`라고 표현하지 않고 각 기업의 최신 FY 라벨을 그대로 표시한다.

## TTM

TTM은 동일 회사·지표·통화·연결 범위의 서로 다른 독립 분기 네 개가 모두 있을 때만 합산할 수 있다. Phase 5C 공개 화면은 이 조건이 완성되지 않으면 TTM을 표시하지 않는다.

## 결측치

누락은 `자료 미수집`, 비교 기준 부재는 `비교 자료 없음`, 공식 업데이트 부재는 `최근 공식 업데이트 없음`으로 구분한다. 0, 0%, 보통 같은 대체값을 만들지 않는다. NaN과 Infinity는 validation에서 거부한다.

## 반올림 규칙

금액은 표시 단위에 맞춰 최대 소수 첫째 자리, 비율과 %p는 소수 첫째 자리, 배수는 소수 둘째 자리, 주당 지표는 최대 소수 둘째 자리로 표시한다. 계산에는 반올림 전 원값을 사용한다.

## 지표별 해석 원칙

숫자 하나를 보편적으로 좋음·나쁨으로 판정하지 않는다. 매출은 마진과 현금흐름, 마진은 제품 구성과 비용, 현금흐름은 설비투자와 운전자본, 재무안전성은 사업 구조와 함께 읽는다. 점수·별점·매수·매도·목표주가를 제공하지 않는다.

## Phase 5D 가치평가 연결

full 지원 기업의 재무 피벗은 `/ko/companies/{slug}/valuation`으로 연결한다. 가치평가 화면은 같은 연간 공시 매출로 계산한 최근 실제 CAGR과 기준 모형의 미래 등가 CAGR, 시장 내재 매출 CAGR만 기간·정의를 병기해 비교한다. 회계기간·통화·지표 정의가 다른 peer나 업종 수치는 연결하지 않으며 없는 비교를 0으로 만들지 않는다.
