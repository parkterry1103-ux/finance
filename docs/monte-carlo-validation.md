| --- | ---: | ---: | ---: | ---: | ---: | ---: |

| Meta | $421.61 | $591.65 | $702.21 | $676.02 | $1,076.41 | $770.95 |

4A 양 끝 조건은 여러 입력이 같은 방향으로 동시에 움직인다. Monte Carlo에서는 모든 유리하거나 불리한 입력이 동시에 발생하지 않으므로 P10·P90 범위가 더 안쪽에 있다. 4A 저장 결과와 엔진 재실행 결과의 회귀 오차는 0이다.

## 수렴성

| 기업 | P10 | P50 | P90 | 기준 |
| --- | ---: | ---: | ---: | --- |
| NVIDIA | 0.026% | 0.001% | 0.029% | PASS |
| Meta | 0.119% | 0.063% | 0.042% | PASS |

두 회사 모두 10,000·25,000·50,000회에서 상위 3개 입력 순서가 `전망 매출 CAGR → WACC → 정상 영업이익률`로 유지됐다.

## 자동 검증

- seeded PRNG 동일 sequence
- 삼각분포 bounds와 mode
- P5 ≤ P10 ≤ P25 ≤ P50 ≤ P75 ≤ P90 ≤ P95
- Spearman +1/-1 fixture와 모든 출력의 `|ρ| ≤ 1`
- 25,000회 동일 seed 재실행 결과 완전 일치
- 가격일과 가치평가일 일치 조건
- 제외율 5% 이하
- 4A 세 시나리오 수치 회귀
- 브라우저 계산 코드와 `Math.random` 부재
- 기업별 정적 snapshot dynamic import
- 금지된 가격 확정·향후 방향 표현 부재

## 브라우저·성능 검증

Chromium과 WebKit에서 NVIDIA·Meta 각각 1440×900, 1280×800, 1024×768, 768×1024, 390×844, 360×800, 320×700을 검사했다. 총 28개 조합에서 본문 가로 overflow, 시장가격 marker clipping, 분위수 라벨 겹침, 긴 숫자 잘림과 기존 레이아웃 붕괴가 모두 0건이었다. 320px 상세 표는 본문을 밀지 않고 표 영역 안에서만 가로 스크롤된다.

실제 macOS Safari에서도 두 기업의 섹션 이동과 표시를 확인했다. NVIDIA는 상세 가정·방법론을 펼쳐 50,000회 실행, 0개 제외, 수렴성 표와 25,000→50,000회 상대 차이를 확인했고, Meta는 시장가격 $681.31 marker와 52.8백분위 설명이 일치했다.

최종 build는 entry `index-FTTOuYDb.js` 752,374 bytes(gzip 203,412)로 기준 build의 752,374 bytes와 같다. 기업 목록 chunk도 64,461 bytes로 동일하다. 리포트 route는 55,980→68,410 bytes이며, Monte Carlo snapshot은 NVIDIA 8,250 bytes, Meta 8,201 bytes의 별도 lazy chunk로 분리된다. 선택하지 않은 기업 snapshot은 선로딩하지 않는다. Release Gate는 21개 검사를 통과했고 dynamic chunk 15개, zero-byte asset 0개, Function 12개를 확인했다.
