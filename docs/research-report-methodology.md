# 기업 리서치 리포트 방법론

## 증거 모델

리포트의 문장은 `사실`, `계산`, `해석`으로 분류한다.

- 사실: SEC EDGAR, 기업 IR, FRED·IEA 같은 원문 source ID와 기준일을 반드시 가진다.
- 계산: 사용 metric, 산식 또는 선행 계산 근거, 기준일을 가진다. 과거 영업이익률은 동일 기간 영업이익을 매출로 나눈다.
- 해석: 하나 이상의 사실 또는 계산 evidence ID에 연결한다. 원문이 직접 말하지 않은 인과나 확률을 확정적으로 표현하지 않는다.

차트 점은 표시 값과 source ID를 함께 저장한다. SVG에는 접근 가능한 이름과 요약이 있고, 펼칠 수 있는 원자료 표가 같은 값을 제공한다. 출처 목록은 각 evidence와 차트 표에서 역참조할 수 있다.

## FCFF 가치평가

공개 리포트는 4A에서 검증한 결정론적 엔진을 그대로 사용한다.

```text
NOPAT = EBIT × (1 - 정상세율)
FCFF = NOPAT + 감가상각 - 설비투자 - 운전자본 증가
WACC = 자기자본비용 × 자기자본가중치 + 세후부채비용 × 부채가중치
기업가치 = 명시적 FCFF 현재가치 + 계속가치 현재가치
주주가치 = 기업가치 + 현금 + 비영업자산 - 부채 - 리스부채 - 기타 청구권
주당 결과 = 주주가치 ÷ 희석주식수
```

계속가치는 영구성장 방식이며 `WACC > 영구성장률`을 요구한다. 장기 ROIC가 있으면 `장기 재투자율 = 영구성장률 ÷ 장기 ROIC`를 사용한다. 계속가치 비중은 기업가치에서 할인된 계속가치가 차지하는 비율이다.

## 조건·민감도·역산

- 보수·기준·확장 조건은 4A `scenarioInputs`의 성장률, 마진, WACC 구성, 영구성장률을 독립 적용한다.
- WACC×영구성장률 표는 기준 WACC와 영구성장률에서 각각 ±1.0%p 범위를 0.5%p 간격으로 계산한다.
- 기업 driver 표는 첫 전망연도 성장률의 75%·87.5%·100%·112.5%·125%와 기준 영업이익률 ±4%p 범위를 사용한다.
- 역산 DCF는 관측 가격과 모형 주당 결과가 일치하도록 명시적 전망 기간 매출 성장 경로를 푼다. 시장의 단일한 기대를 뜻하지 않는다.
- ROIC fade 진단은 기준 조건에서 장기 ROIC만 기준 WACC+1%p로 바꾼다. 발생 확률을 부여한 별도 조건이 아니라 계속가치 의존도 점검이다.

## 기준일

리포트 작성일, 재무 기준일, 가격 기준일, 가치평가 기준일, 희석주식수 기준일, 자본구조 기준일을 서로 대체하지 않는다. 화면 표지와 근거 원장에서 각각 표시한다. 현재 가격은 비교점으로만 사용하고 가격 차이를 행동 지시 언어로 바꾸지 않는다.

## 한계

이 파일럿은 실시간 시세나 분석가 컨센서스를 사용하지 않는다. 공식 공시와 명시적 내부 가정으로 구성되며, 업종 benchmark는 범위 점검에만 쓴다. 현재 투자자본의 완전한 시계열이 없으므로 과거 ROIC를 임의 생성하지 않고 장기 ROIC 가정과 fade 진단만 보여준다. 모델 결과는 입력 가정에 민감하며 이용자의 최종 판단을 대신하지 않는다.
