# 기업 리서치 리포트 방법론

## 내부 근거와 공개 문장

내부 데이터는 확인된 원문, 계산, 분석 연결을 구분하고 source ID·metric ID·calculation ID·공시 accession·기간·단위·통화를 보존한다. 확인된 숫자는 source, 계산은 입력 metric과 산식, 분석 문장은 선행 evidence가 없으면 validator에서 실패한다.

공개 화면은 이 분류명을 배지나 열로 표시하지 않는다. 문장은 변화, 중요성, 지속성, 재무 의미, 판단 변경 조건, 다음 확인 순서로 자연스럽게 쓰고 핵심 출처 번호만 문장 끝에 둔다. 기술 식별자는 출처 목록의 접힌 영역에서만 확인할 수 있다.

## 시점형 snapshot

각 리포트는 `reportId`, `version`, `publishedAt`, `updatedAt`, `newsCutoffAt`, `marketDataAsOf`, `priceAsOf`, `financialDataAsOf`, `valuationAsOf`, `benchmarkAsOf`를 가진다. 서로 다른 날짜를 하나로 합치지 않는다. 뉴스는 cutoff 이후 자료를 포함할 수 없고 가격과 DCF 결과는 같은 valuation snapshot에서 비교한다.

## 뉴스 선별

기업당 최대 3건만 사용한다. 수요, 가격, 제품 구성, 점유율, 해자, 성장률, 마진, Capex, 운전자본, 현금흐름, 자본구조, 규제비용, 핵심 고객, Terminal ROIC, WACC 또는 영구성장률을 바꿀 수 있는 사건만 포함한다.

각 사건은 출처·발표일·확정/진행 상태, 영향을 받는 assumption/metric, 무슨 일·중요성·전달 경로·지속성·기존 판단 영향·다음 확인을 가진다. 홍보 반복, 단순 주가 기사, 중요하지 않은 인사, 출처 불명 루머는 제외한다. 발표만으로 장기 가정을 바꾸지 않고 공식성, 상용화, 고객 채택, 매출 시점, 대체/보완 관계와 반대 근거를 구분한다.

시장 전체 금리·유동성·위험선호와 기업 고유 실적·가이던스·수요·규제 요인을 별도로 설명한다. 상대수익률은 인과 증명이 아니므로 원인을 확정하지 않는다.

## 해자·재무건전성·산업 역할

해자는 기업과 관련 있는 전환비용, 네트워크, 규모, 통합 생태계, 데이터, 기술, 고객 관계만 평가한다. 각 항목은 현재 근거, 실적으로 이어지는 경로, 약화 조건, 다음 지표를 가진다.

재무건전성은 실제 데이터가 있는 현금·비영업 금융자산, 부채·리스, 순현금성 여력, 영업현금흐름, Capex, 주식보상, 희석주식 수를 사용한다. 잔고보다 불황에도 연구개발·영업·핵심 투자를 유지할 수 있는지를 먼저 설명한다.

산업 역할은 하나의 등급이 아니라 현재 위치, 산업 성장과 매출 연결, 상승기·하락기 효과, 대체 가능성, 사이클 뒤에도 남는 경쟁력과 판단 변경 조건으로 설명한다.

## FCFF 가치평가

NVIDIA와 Meta는 4A에서 검증한 Driver-based FCFF DCF를 사용한다.

```text
NOPAT = EBIT × (1 - 정상세율)
FCFF = NOPAT + 감가상각 - 설비투자 - 운전자본 증가
WACC = 자기자본비용 × 자기자본가중치 + 세후부채비용 × 부채가중치
기업가치 = 명시적 FCFF 현재가치 + 계속가치 현재가치
주주가치 = 기업가치 + 현금 + 비영업자산 - 부채 - 리스부채 - 기타 청구권
주당 결과 = 주주가치 ÷ 희석주식수
```

NVIDIA는 AI 인프라 수요, 마진, 재투자와 장기 ROIC가 가치의 주요 동인이어서 이 방식을 쓴다. Meta는 광고 현금창출과 AI Capex·감가상각을 한 모형에서 함께 봐야 하므로 FCFF가 적합하다. 배당할인·잔여이익·FCFE는 주 방법으로 계산하지 않는다.

## 가격·산업 비교·Reverse DCF

괴리율은 `시장가격 ÷ 기준 시나리오 가치 - 1`이다. 양수는 모형 대비 프리미엄, 음수는 할인, ±0.5% 미만은 유사한 수준으로 표현한다. 이는 목표주가·상승여력·고평가·저평가 판정이 아니다.

Reverse DCF는 정상 마진, WACC, 재투자, 영구성장률, Terminal ROIC와 전망기간을 고정하고 현재 가격과 일치하는 매출 CAGR을 푼다. 회사가 반드시 달성해야 하는 성장률로 단정하지 않는다.

NYU Stern 값은 직접 선정 동종기업 중앙값이 아니라 같은 기준일의 미국 업종 집계치다. WACC와 ROIC 가정의 범위 점검에만 사용하고 회사의 누락 값을 대체하지 않는다.

## 조건과 민감도

보수·기준·낙관 조건과 두 5×5 민감도 표는 4A 입력을 기존 엔진에 다시 넣어 계산한다. 기준 셀은 색 외에 `기준 가정` 텍스트를 가진다. Terminal Value는 명시적 FCFF 현재가치, 할인된 계속가치, 기업가치 비중, 영구성장률, Terminal ROIC, 재투자율과 WACC를 함께 표시한다.

## 한계

실시간 시세·컨센서스·런타임 뉴스 요청을 사용하지 않는다. 뉴스 snapshot 이후 사건은 반영되지 않는다. 모델 결과는 가정에 민감하며 투자 의견이나 행동 지시가 아니다.
