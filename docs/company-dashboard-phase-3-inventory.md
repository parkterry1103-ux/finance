## 현재 데이터 흐름

- 상세 진입점은 `src/routes/CompaniesRoute.tsx`의 `CompanyProfilesRoute`이며, 화면은 `CompanyResearchProfilePage`가 그립니다.
- 회사 registry는 `src/content/company-profiles/entries.ts`, 회사 식별자는 `src/data.ts`와 회사 이벤트 registry를 함께 사용합니다.
- 상세 view model은 `src/content/company-profiles/selectors.ts`에서 profile, 산업 흐름, 관계, 이벤트, 병목, 수요·공급, 리포트, 기존 해설, 공식 지표와 출처를 조합합니다.
- 기존 상세 route는 전역 `/api/market-prices?limit=200` 요청 결과만 전달받습니다. 상세 component 자체의 추가 요청은 없습니다.
- 공식 재무 연결 코드는 `src/services/financials.ts`와 기존 `/api/financials`에 있지만 현재 8개 기업 상세 route에서는 사용하지 않습니다. fallback 숫자는 `원문 확인` 문자열이어서 KPI로 사용할 수 없습니다.
- 현재 공식 KPI는 회사 IR 리포트의 `actual` metric 또는 회사 이벤트 본문에 명시된 값에 한정됩니다. 가치평가 배수 registry는 없습니다.
- 거시 정의는 `src/content/macro/indicators.ts`, 검토된 방향은 `src/content/macro/briefs.ts`, 출처는 공통 source registry를 사용합니다.
- 별도 차트 라이브러리는 사용하지 않으며 기존 CSS/SVG 패턴만 있습니다.

## 누락·품질 처리

- 없는 재무·현금흐름·밸류에이션 값은 만들거나 `0`으로 바꾸지 않는다.
- 이벤트에 포함된 계획·전망·협약 값은 실제 실적과 분리하고 상태를 명시한다.
- 회계 기간이 다른 값은 같은 시계열로 연결하지 않는다.
- 각 KPI는 원문 통화, 단위, 기간, 출처, 기준일을 함께 가진다.
- 거시 카드에는 숫자를 복제하지 않고 검토된 방향과 기준일을 표시한다. 상세 최신값은 기존 거시경제 화면에서 확인하도록 연결한다.
- 기준일은 profile 검토일, 이벤트일, 리포트 metric 기준일 중 실제 데이터에서 가장 최근인 날짜로 계산한다.

## 기존 상세 영역 보존 대상

- 사업 설명·제품·확인 질문
- 정적 산업 흐름
- 최근 회사 이벤트와 다음 확인 항목
- 수요·공급 및 병목
- 관련 기업과 관계 근거
- 기존 해설 카드
- 공식 지표와 리포트·원문 출처
- 주의 문구

위 항목은 기본 접힘 상태의 `상세 데이터·출처` 안으로 이동하며 route와 원본 registry는 유지한다.
